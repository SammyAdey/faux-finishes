# About / Contact / Policies Overrides

## Shared page hero
- Use `PageHero`: copy left, full-height image right with `#c8c8c0` divider. No cards, no rounded media.
- Stack image below copy on small screens.

## About (`/about`)
- Eyebrow `About.` + Canela hero + header image
- Two-column body + aside with hairline border
- Aside labels: `text-sm font-normal text-ink` (not uppercase tracked)
- Add the company story as a simple vertical timeline below the introduction; team photo above it when supplied
- Follow with sourced testimonials
- End with `ContactCta`

## Contact (`/contact`)
- Eyebrow `Contact.` + Canela statement (may use secondary colour on second line) + header image
- Form left / details right
- Detail labels match page eyebrow style

## Policies (`/policies-governance`)
- Eyebrow `Governance.` + Canela title + header image
- Policy blocks: top hairline border, Canela or light serif titles (`font-light`), no cards
- End with `ContactCta`
